# 멀티 캘린더

월간 캘린더를 메인 화면으로, 일정·습관·식단·회고를 탭으로 전환하며 기록하는 웹 캘린더입니다.
PC와 모바일 브라우저 모두에서 사용할 수 있습니다.

## 주요 기능

- **보기 전환**: 일간 / 주간 / 월간, 그리고 별도의 연표·통계 화면
- **탭(카테고리)**: 일정형(시간·기간), 체크형(습관), 기록형(식단·회고 등 메모)
  - 탭 이름·아이콘·형식·항목 편집, 순서 변경, 추가·삭제
- **일정별 색상**: 일정마다 색상을 따로 지정
- **연표·통계**: 핵심 지표, 1년 기록 한눈에 보기, 월별 추이, 습관 항목별 달성률, 연표
- **모바일**: 좌우 스와이프로 이동, 날짜를 누르면 아래에서 기록 시트가 열림

## 사용 방법

`index.html` 파일 하나로 동작합니다. 브라우저로 열거나, GitHub Pages 주소로 접속하면 됩니다.

## 데이터 저장

- **가족 캘린더 (Supabase 연결 시)**: 이름 + 숫자 4자리로 로그인하면 가족이 같은 기록을 함께 보고 씁니다.
  다른 기기에서 고친 내용도 바로 반영됩니다. 가족 자리는 기본 3명입니다.
- **이 기기에서만 쓰기**: 로그인하지 않으면 사용하는 브라우저(localStorage)에만 저장됩니다.

Supabase 설정: `supabase/schema.sql`을 SQL Editor에서 실행하고, 익명 로그인(Anonymous sign-ins)을 켠 뒤
`index.html`의 `SUPABASE_URL`, `SUPABASE_KEY`(공개용 publishable/anon 키)를 채웁니다.

## 앞으로 확장할 기능

- 가족이 함께 쓰는 기록장(일기), 가계부, 식단표
- Supabase 연동(로그인, 기기 간 동기화)
